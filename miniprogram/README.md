# 环宇寻声 (GlobeSound 微信小程序版)

> 软硬件结合：万向地球仪（底座与球体分离/无固定轴）+ 维特智能 BWT901BLECL（BLE 5.0 姿态传感器）+ 微信小程序。  
> 硬件成本控制在百元内（传感器闲鱼约 ¥45，地球仪约 ¥25–60）。

通过 BLE 蓝牙直连置于球体内部的姿态传感器，实时读取球顶正上方最高点的地理经纬度，地图同步平滑跟随，并支持两大核心模式：
1. **📻 环球电台模式**：全球 1,648+ 热门网络电台（对标 Radio Garden、RoamDial、Radio Browser），全国 34 个省级行政区与全球文化重镇全覆盖。
2. **🐼 萌宝环球乐园模式**：专为幼儿（2岁+）设计的启蒙探索模式，大容错邻近吸附、内置全套微软 Edge-TTS 绘本级自然普通话语音（`zh-CN-XiaoxiaoNeural`），让孩子听小萌友生动讲故事！

## 核心特性与解决难点

### 1. 无轴万向地球仪与 20cm 误差解决方案
- **无固定轴球体全向兼容**：
  现代万向地球仪底座与球体分离，球体可自由 360° 全向滚动。本项目采用纯重力解算，传统的 23.5° 地轴倾角在数学模型中与读数无强制相关性，任何地点只要转到球顶最高点即可直接出坐标。
- **20cm 直径误差的工程缓冲**：
  20cm 直径地球仪周长仅约 $62.8\text{cm}$，即 **$1^\circ$ 经纬度在球体表面仅对应 $1.7\text{mm}$**。人工用手转动的机械顶点误差通常在 $5\sim 10\text{mm}$（约折合 $3^\circ \sim 6^\circ$ 的角误差）。
  - **电台模式**：核心城市与热门电台多级缓冲区检索（$0.5^\circ \to 3^\circ \to 8^\circ$ 阶梯式回退），并配有海事短波台兜底，杜绝静音死区。
  - **萌宝乐园模式**：全球划分为 24 个 $12^\circ \sim 45^\circ$ 的超大动物与地理生态区（Voronoi 质心吸附），陆地海洋 100% 全覆盖，保证孩子转到任何角度都有丰富正反馈。

### 2. 纯重力姿态解算（无磁漂移）
- 仅使用三轴加速度计的重力方向，不依赖磁力计，彻底消除地球仪金属转轴与周围电子设备的地磁干扰与偏航漂移。
- 基于 Wahba 问题与 Jacobi SVD 特征值分解，四点向导式（北极、0°,0°、新加坡、悉尼）求解传感器坐标系到地球 ECEF 坐标系的旋转矩阵，算法残差 < 0.0001°。

### 3. 全套微软 Edge-TTS 自然人声（零网络延迟，包内离线播放）
- 幼儿注意力时间短，网络 TTS 存在缓冲延迟或断网风险，而波形合成器声音生硬。
- 本小程序将 24 个生态大区的高清故事音频（微软经典童趣绘本配音 `zh-CN-XiaoxiaoNeural`）**全量打包内置于小程序包中**（`audio/kids/*.mp3`），通过 `InnerAudioContext` 零延迟毫秒级秒开播报，伴随柔和震动反馈（`wx.vibrateShort`）。

### 4. 自动降频节能与渲染节流
- **硬件降频**：连接成功后自动向 BWT901BLECL 传感器下发 `FF AA 03 06 00`，将采样率调整至 10Hz，让 200mAh 电池续航延长至 15~20 小时。
- **渲染节流**：`onLiveReading` 限制渲染刷新上限为 6~7Hz，杜绝频繁 `setData` 造成的手机发热和电量骤减。

## 快速使用

### 1. 导入微信开发者工具
1. 打开 **微信开发者工具**。
2. 选择 **导入项目**，目录选择 `miniprogram/`。
3. AppID 选择测试号或填入自己的 AppID。
4. “本地设置”中开启“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”（收听外部电台流需要）。

### 2. 真机预览与调试
- 点击开发者工具上方 **预览**，使用手机微信扫码。
- **前提要求**：
  1. 手机需开启 **蓝牙** 与 **定位服务**（Android 系统扫描蓝牙设备要求开启定位权限）。
  2. 维特智能 BWT901BLECL 传感器若已被手机端的 WitMotion 官方 App 占用，将无法被搜索到。**请先彻底关闭其他已连接的 App**。

### 3. 操作流程
1. 点击底部 **连接蓝牙**，搜索并选中 `WT901BLE...` 传感器。
2. 首次连接可根据向导进行 **四点标定**（北极、0°,0°、新加坡、悉尼）；即使未标定，程序也内置默认方位映射，可立即开始转动体验。
3. **开始使用**：
   - **切换模式**：在顶部可随时轻点 `📻 环球电台` 或 `🐼 萌宝乐园`。
   - **转动地球仪**：
     - 在 **环球电台** 模式下：停稳后自动搜索周围电台并提示播放，支持曲风切换和同城切台。
     - 在 **萌宝乐园** 模式下：转动中动态切换当前生态区，停稳后播放微软 Edge-TTS 绘本级自然故事语音，点击卡片或“听小萌友讲故事”可随时重播。
