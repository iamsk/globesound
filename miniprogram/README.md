# 环宇寻声 (GlobeSound 微信小程序版)

> 原名 GlobeSound / 地球之声，全新升级版：**「环宇寻声」**。  
> 软硬件结合：万向地球仪 + 维特智能 BWT901BLECL（BLE 5.0 九轴姿态传感器）+ 微信小程序。

通过 BLE 蓝牙直连置于球体内部的姿态传感器，实时读取球顶正下方（子午圈最高点）的地理经纬度，地图同步平滑跟随，并支持两大核心模式：
1. **📻 环球电台模式**：全球 1,600+ 热门网络电台（对标 Radio Garden、RoamDial、Radio Browser），全国 34 个省级行政区与全球文化重镇全覆盖。
2. **🐼 萌宝环球乐园模式**：专为幼儿（2岁+）设计的启蒙探索模式，大容错邻近吸附、可爱卡通音效、大字语音气泡、名胜与动物叫声。

## 核心特性与解决难点

### 1. 20cm 地球仪人工转动误差的工程解决方案
20cm 直径地球仪周长仅约 $62.8\text{cm}$，即 **$1^\circ$ 经纬度在球体表面仅对应 $1.7\text{mm}$**。人工用手转动的机械顶点误差通常在 $5\sim 10\text{mm}$（相当于 $3^\circ \sim 6^\circ$ 的角误差），对于梵蒂冈、新加坡乃至部分省份极难精准“停”在其内部。
为此我们设计了分级自适应吸附算法：
- **电台模式**：
  - 核心城市与热门电台多级缓冲区检索（$0.5^\circ \to 3^\circ \to 8^\circ$ 阶梯式回退）。
  - 全国 34 个省份各配有代表性省级总台与省会电台，并在大洋海域设置国际海事/航海短波兜底电台，避免“静音死角”。
- **萌宝乐园模式**：
  - **超高容错宏观区域划分（Voronoi 质心吸附）**：将全球划分为 24 个 $12^\circ \sim 45^\circ$ 的超大动物与地理主题区（如：中国大熊猫基地、非洲大草原狮子王、澳大利亚考拉袋鼠、南极帝企鹅、北极白熊等）。
  - **绝对无死区**：转到任何陆地、甚至太平洋大西洋中央，也会就近吸附到蓝鲸、海豚或最近的大陆奇趣动物，保证孩子每次转动停下都有满满的正反馈。

### 2. 纯重力姿态解算（无磁漂移）
- 仅使用三轴加速度计的重力方向，不依赖磁力计，彻底消除地球仪金属转轴与周围电子设备的地磁干扰与偏航漂移。
- 基于 Wahba 问题与 Jacobi SVD 特征值分解，四点向导式（北极、0°,0°、新加坡、悉尼）求解传感器坐标系到地球 ECEF 坐标系的旋转矩阵，算法残差 < 0.0001°。

### 3. 萌宝专属拟音合成器（零外部依赖、零网络延迟）
- 幼儿注意力时间短，网络 TTS 存在缓冲延迟或断网风险。
- 本小程序内置 `utils/synth.js`，基于微信原生 WebAudio API（`wx.createWebAudioContext()`），使用多振荡器（Sine、Triangle、Sawtooth、White Noise）配合 ADSR 包络，**纯代码实时合成动物动作音效**（大熊猫咔嚓嚼竹子、袋鼠弹簧蹦跳、狮子咆哮、海浪呼啸、清脆八音盒等），毫秒级发声并伴随轻微震动反馈（`wx.vibrateShort`）。

## 快速使用

### 1. 导入微信开发者工具
1. 打开 **微信开发者工具**。
2. 选择 **导入项目**。
3. 项目目录选择 `/Users/zhangbin/workspace/globesound/miniprogram`。
4. AppID 选择你的测试号或填入已有小程序的 AppID。
5. 确认“本地设置”中开启“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”（收听外部音频流需要）。

### 2. 真机预览与调试
- 由于电脑桌面通常无标准 BLE 广播发射与扫描支持，请点击开发者工具上方 **预览**，使用手机微信扫码。
- **必备前提**：
  1. 手机需开启 **蓝牙** 与 **定位服务**（Android 系统扫描蓝牙设备必须开启定位）。
  2. 维特智能 BWT901BLECL 传感器若已被手机端的 WitMotion 官方 App 占用，将无法被搜索到。**请先彻底关闭其他已连接的 App**。

### 3. 操作流程
1. 点击底部 **连接蓝牙**，搜索并选中 `WT901BLE...` 或 `WT...` 传感器。
2. 首次连接将自动弹出提示引导进入 **标定页**：
   - 依次把 **北极**、**(0°, 0°)**、**新加坡**、**悉尼** 转动到子午圈最高点正下方。
   - 每次停稳后点击 **确认**，等待约 1 秒提示“已记录 ✓”，自动进入下一步。
   - 4 个点记录完毕后即显示标定残差（RMS 一般在 1°–2° 之间）。
3. 点击 **开始使用** 返回主页：
   - **切换模式**：在顶部可随时轻点 `📻 环球电台` 或 `🐼 萌宝乐园`。
   - **转动地球仪**：
     - 在 **环球电台** 模式下：停稳后自动搜索周围电台并提示播放，支持曲风切换和城市内切台。
     - 在 **萌宝乐园** 模式下：停稳后弹出巨幅卡通萌宠卡片（如大熊猫🐼、企鹅🐧、考拉🐨等），点击卡片自动播放离线拟音并触发趣味语音气泡，下方还展示邻近可探索区域。
