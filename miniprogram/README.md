# globesound 微信小程序版

基于维特智能 BWT901BLECL（BLE 5.0 九轴姿态传感器）+ 万向地球仪的微信小程序。

通过 BLE 蓝牙直连球体内的传感器，实时读取球顶正下方（子午圈最高点）的地理经纬度，在地图上同步跟随，并自动锁定播放离读数点最近的网络广播电台。

---

## 核心特性

- **BLE 蓝牙直连**：原生封装微信蓝牙 API（`wx.openBluetoothAdapter` / `wx.createBLEConnection` / `wx.notifyBLECharacteristicValueChange`），自动识别 `WT` 开头的 WitMotion 传感器设备。
- **纯重力姿态解算**：
  - 仅使用三轴加速度计的重力方向，不依赖磁力计（彻底消除地磁、金属底座干扰与偏航角漂移）。
  - 基于 Wahba 问题与 Jacobi SVD 特征值分解，求解传感器坐标系到地球 ECEF 坐标系的正交旋转矩阵。
  - 自动识别加速度计符号约定，实测算法精度达到解析解级别（误差 < 0.0001°）。
- **四点向导式标定**：北极、(0°, 0°)、新加坡、悉尼，完成标定后自动计算并展示残差（RMS），持久化缓存到本地。
- **动态跟随地图**：微信原生 `<map>` 组件，支持标准与卫星混合视图，读数点状态变色（转动中为青色，静止已读数为琥珀色）。
- **全球网络电台**：
  - 本地预置深圳电台流（`data/stations_extra.json`），免联网秒级启动。
  - 异步加载 Radio Browser 社区在线电台库，支持 10 种以上曲风分类筛选。
  - 自动归集 30km 同城电台，支持前一首/后一首无缝切换、播放超时自动跳台。

## 快速使用

### 1. 导入微信开发者工具
1. 打开 **微信开发者工具**。
2. 选择 **导入项目**。
3. 项目目录选择 `/Users/zhangbin/workspace/globesound/miniprogram`。
4. AppID 选择你的测试号或填入已有小程序的 AppID。
5. 开发环境建议：基础库版本 ≥ `3.0.0`。

### 2. 真机预览与调试
- 由于桌面开发者工具通常不支持完整扫描真实 BLE 广播，请点击开发者工具右上角 **预览** 或 **真机调试**，使用手机微信扫码运行。
- **注意**：
  1. 手机需开启 **蓝牙** 与 **定位服务**（Android 系统要求开启定位权限才能扫描 BLE 设备）。
  2. 维特智能 BWT901BLECL 传感器在开机后，若已被手机端的 WitMotion 官方 App 占用连接，将无法被其他设备搜索到。**请先关闭其他已连接的 App**。

### 3. 操作流程
1. 点击底部 **连接蓝牙**，搜索并选中 `WT901BLE...` 传感器。
2. 首次连接将自动弹出提示引导进入 **标定页**：
   - 依次把 **北极**、**(0°, 0°)**、**新加坡**、**悉尼** 转动到子午圈最高点正下方。
   - 每次停稳后点击 **确认**，等待约 1 秒提示“已记录 ✓”，自动进入下一步。
   - 4 个点记录完毕后即显示标定残差（RMS 一般在 1°–2° 之间）。
3. 点击 **开始使用** 返回主页：
   - 转动地球仪，地图中心与读数将实时跟随。
   - 静止约 1 秒后读数锁定（琥珀色），并在 3° 范围内搜索并锁定最近的网络电台。
   - 点击 **开始收听**，即可收听当地广播。
